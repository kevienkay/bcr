# BC 5.2.5 设计稿 → bcr 实现交接说明

> 设计稿位置：`BC菜单和状态栏/`（入口 `index.html`）
> 目标仓库：`bcr`（Rust + eframe/egui 0.36，`src/gui/` 已有约 5 万行实现）
> 本文是**唯一入口文档**：实现方先读本文，再按需打开 `index.html` 与对应 `screens/*.html`。
> 一句话定位：**这不是从零实现，而是把现有 egui 界面按设计稿对齐、补齐缺口。**

---

## 一、怎么把设计稿交给编码 Agent

三种方式，任选其一（推荐 A）：

| 方式 | 做法 | 适合 |
|---|---|---|
| **A. 目录 + 入口文档（推荐）** | 把整个 `BC菜单和状态栏/` 复制进仓库（如 `bcr/design/`），让 Agent 读 `design/BC菜单和状态栏/交接/实现交接.md` | 完整实现，Agent 可随时对照 8 张会话稿 |
| B. 单文件摘要 | 只给 `交接/实现交接.md` + `交接/design-tokens.json` | 只做菜单/状态栏/token 对齐 |
| C. 逐屏投喂 | 一次给一张 `screens/xxx.html` + 该屏对应的源码锚点 | 每次只改一个视图 |

复制命令（在 bcr 仓库根目录执行）：

```bash
mkdir -p design && cp -R "/path/to/BC菜单和状态栏" design/
```

> 注意：设计稿是给人看的 HTML，**不要**让 Agent 直接把 HTML/CSS 翻译成 egui 代码。
> 它要读的是：本文件的结构与尺寸表、`design-tokens.json` 的色值与阶梯、以及 `screens/*.html` 里的**样子与状态**。

## 四、Token 对齐（**先做决策，再动手**）

设计稿的颜色是从 BC 截图逐像素采样的，与 `theme.rs` 现值有出入。**逐条给出动作**，不要整表覆盖：

### 4.1 建议保持 bcr 现值（差异在容差内，或现值更适合 egui 渲染）

| Token | 设计稿 | theme.rs（浅色） | 动作 |
|---|---|---|---|
| 列头底 | `#F7F9F8` | `column_head_bg` `#F9FAFC` | 保持 |
| 行号槽底 | `#ECEFF0` | `gutter_bg` `#F0F1F5` | 保持 |
| 左右分隔槽底 | `#F0F1F5` | `mid_bg` `#F4F5F8` | 保持 |
| 文件夹蓝 | `#3C6EBE` | `folder_color` `#3C6EBE` | 一致 |
| 修改前景 | `#A9761A` | `diff_modify` `#B08C28` | 保持（设计值更暖，可选微调） |
| 圆角 | 4–6 | `CORNER = 4.0` | 一致 |

### 4.2 建议按设计稿微调（观感差异明显）

| Token | 设计稿 | theme.rs（浅色） | 动作 |
|---|---|---|---|
| 删除/仅左 前景 | `#E01E10` | `diff_delete` `#C43C3C` | 调为设计值，红更饱和、更接近 BC |
| 新增 前景 | `#1F7A3D` | `diff_insert` `#288C50` | 可保持；若要与设计一致则微调 |
| 强调/选中 | `#0078F0` | `accent` `#285AC8` | 调为设计值（菜单高亮 `#228EF4` 另见 §5.1） |
| 行高 | 列表 26 / 代码 20 | `ROW_H = 22.0` | 拆成两个常量：`ROW_H_LIST = 26`、`ROW_H_CODE = 20` |
| 正文字号 | 12–13 | `FONT_SIZE = 14.0` | 建议列表 12.5 / 代码 12 / 菜单 13（egui 用 `FontId`） |
| 分隔槽宽 | 22 | `MID_GAP = 26.0` | 调为 22 |

### 4.3 ⚠️ 语义冲突：必须先决策，**不要直接改**

设计稿（依据本轮需求）定义：

```
仅左侧 = 红 · 仅右侧 = 黄/琥珀 · 已修改 = 蓝 · 二进制不同 = 紫
```

`theme.rs` 现值是另一套语义：

```
bg_left_only   = 红 rgba(246,96,96,40)
bg_right_only  = 绿 rgba(96,196,118,38)      ← 设计要黄
bg_modified_l/r= 红 / 绿                      ← 设计要蓝
```

两条路：

- **路线 1（推荐，改动小）**：保留 bcr 现有「仅左红 / 仅右绿 / 已修改红绿」语义，只把**设计稿的色值精度**（饱和度、透明度）对齐；`二进制不同` 仍用紫色。
- **路线 2（严格照设计）**：把 `bg_right_only` 改黄、`bg_modified_*` 改蓝，同步改 `status_orphan / status_differ` 等前景色，并更新 `ui_review/` 里的基准图与 `uikit_tests.rs` 里断言颜色的用例。

**这个决策请由人拍板后写进任务说明**，否则实现方会在两套语义间反复。

## 五、需要新增的能力（设计稿有、代码暂无）

### 5.1 菜单项「可用 / 置灰 / 勾选」

- 现状：`menubar.rs:36 menu_item(ui, label, shortcut)` 没有 enabled 参数。
- 改法：扩展为 `menu_item(ui, label, shortcut, enabled: bool)`（内部 `ui.add_enabled(enabled, egui::Button::new(...))`），并在所有调用点补 `true`；勾选项用 `egui::Button::new(...).selected(true)` 或加 `✓` 前缀列。
- 菜单高亮：egui 自带 hover 高亮，需把选中色设为设计值 `menu-hl #228EF4`（白字），而不是默认浅色底。

**置灰规则（共 16 项，来自 `screens/menus.html`）**

| 菜单 | 置灰项 | 触发条件 |
|---|---|---|
| 会话 | 关闭标签页 · 关闭其它标签页 · 比较父文件夹 | `tabs.len() <= 1` |
| 窗口 | 选择上一个标签页 · 选择下一个标签页 · 移动标签页到新窗口 · 合并所有窗口 | `tabs.len() <= 1` |
| 编辑 | 撤销 · 重做 · 剪切 · 复制 · 粘贴 · 删除 · 全选 · 选择选择内容 | 当前是**只读比较会话**（`Tab::Diff / Dir / Csv / Image / Media / Patch`） |
| 编辑 | 上述各项**全部可用** | 当前是 `Tab::Merge` / `Tab::TextEdit`（左右可编辑） |
| 视图（图片） | 重置差异偏移 | 当前偏移为 0 |
| 视图（文件夹） | 比较父文件夹 | 无父目录 |

### 5.2 视图菜单按会话类型整组切换

`view_menu`（`menubar.rs:802`）目前大概率是长列表；设计稿要求**按 `Tab` 变体换整组**：

| 会话 | 视图菜单内容 |
|---|---|
| 文本比较 | 显示全部/差异/相同 · 可见空白 · 语法加亮 · 自动换行 · 边并排布局 · 缩略图 · 图例/日志/工具栏 |
| 文件夹比较 | 12 种过滤（全部/差异/相同/独有/左右较新…）· 总是显示文件夹 · 仅比较文件 · 忽略文件夹结构 · 忽略不重要差异 · 列/图例/日志/工具栏 |
| 十六进制 | 全部/差异/相同 · 字节地址(偏移/小尾/大端) · 布局(边并排/上-下) · 缩略图 · 文件信息 |
| 表格 | 全部/差异/相同 · 隐藏相同列 · 列宽自适应 · 可见空白 · 行号 · 边并排/上-下 · 缩略图 |
| 图片 | 容差(1)/不匹配范围(2)/混合(3) · 自动缩放 · 顺/逆时针旋转 · 水平/垂直翻转 · 重置差异偏移(置灰) · 比较元数据 · 全屏 · 缩放 |
| 媒体 | 全部/差异/相同 · 波形 · 频谱 · 元数据 · 图例/日志/工具栏 |
| 文本合并 | 全部/差异/相同 · 冲突 · 上下文 · 图例/日志/工具栏 |
| 主页（无标签） | 显示会话管理 · 显示网络资源 · 工具栏 · 状态栏 · 日志 |

### 5.3 状态栏两行分格

- 现状：`status_bar` 单行 `ui.horizontal`。
- 改为两行，每行 24px、单元格之间 1px 竖线 `#C7CDD4`：

```
第 1 行（通用，所有会话）
[✗ N 个差异部分] [☐ 忽略的不重要差异] [编辑模式 ▾] …… [加载时间: 0.05 秒]

第 2 行（按会话类型）
文件夹：[3 个文件, 4.1 KB] [130 GB 可用] | 维度计数 | [4 个文件, 3.19 KB] [130 GB 可用]
文本  ：每栏 [行号:列号] [注释] [语法上下文]
十六进制：差异字节数 · 相同数 · 当前 1/N
表格  ：差异行数 · 相同数 · 当前单元格 A3 = 3
图片  ：遮罩图例 · 差异像素 · 偏移
媒体  ：差异项 · 播放进度 · 模式
合并  ：冲突数 · 已解决 n/N · 输出路径
主页  ：显示会话管理 / 显示网络资源 · 会话数 · 磁盘
```

各格文案与取值见 `screens/status-bar.html` 与 `交接/design-tokens.json` 的 `statusBar` 段。
