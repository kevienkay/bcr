## 二、怎么把稿子拷到本机

**方式 A：双击** —— 在 Finder 里双击 `安装到本机.command`。
（若被 Gatekeeper 拦住，右键 → 打开 → 仍要打开。）

**方式 B：Terminal 一行**（最稳，推荐）
```bash
bash "$HOME/Downloads/BC菜单和状态栏/BC菜单和状态栏_安装到本机.command"
```

**方式 C：直接手动拷**
```bash
SRC="/Users/ycy/Library/Application Support/Open Design/namespaces/release-stable/data/projects/589d88c6-5d5f-4291-b93e-5173326cb7bb/BC菜单和状态栏"
cp -R "$SRC/." "$HOME/Downloads/BC菜单和状态栏/"
cp -R "$SRC" "$HOME/.openclaw/workspace-huaqi/bcr/design/"
```

三种方式都是**合并**，不会删掉你 `~/Downloads/BC菜单和状态栏/` 里原有的 `README.md`、`截图/`、`菜单md/`。

## 三、怎么交给编码 Agent（bcr 实现）

1. 跑上面的拷贝（它会同时放进 `bcr/design/`，Agent 从仓库根目录就能读到）。
2. 第一个提示词：

   > 读 `design/BC菜单和状态栏/交接/实现交接.md` 和 `design/BC菜单和状态栏/交接/design-tokens.json`，
   > 先只做 P0 和 P1。§4.3 的配色语义冲突未决策，不要擅自改。

3. 文档里有：设计稿→源码映射表（精确到 `menubar.rs:36`、`mod.rs:3152`）、token 差异与动作、
   16 条置灰规则、P0–P3 分阶段任务、验收命令（`cargo test` + `ui_review/analyze.py`）。

> ⚠️ 有一件事需要你先拍板：设计稿说「仅右侧 = 黄、已修改 = 蓝」，而 bcr 现值是「仅右侧 = 绿、已修改 = 红绿」。
> 这是语义冲突，两条路线写在 `交接/实现交接.md` §4.3。
