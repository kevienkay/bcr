# P39-2 差距清单全量实施

> 依据 `docs/P39-UI-study.md`（BC 5.2.5 实测扫描）的三张清单：
> 功能差距 / 快捷键差距 / UI 精修清单，全部实施。
> 流程：每批本地 `cargo test` 全绿 → push → 下一批；全部完成后统一查 CI。

## P39-2a 设置对话框 + 新建标签/窗口 + 快捷键系统化
- 设置对话框 `⌘,`：忽略选项（空白/行尾/大小写/CRLF）+ 编码 + 大小上限集中管理
- 新建标签页 `⌘T` / 新建窗口 `⌘N`
- 快捷键补齐：`⌘,`、`⌘T`、`⌘N`、`⌘L`（转到行）、`⌘G`（查找下一）、`⇧⌘G`（查找上一）、`⌥⌘S`（保存会话）、`⌥⌘C`（清除会话）、`1/2/3`（视图过滤）

## P39-2b UI 精修
- 全局字体（中文苹方/思源黑体 + 等宽 JetBrains Mono）
- diff 配色对齐 BC 柔和色调（删除淡红/插入淡绿/修改淡黄）
- 工具栏图标化（矢量图标替换 emoji）
- 行号 gutter 样式、当前差异行竖条颜色

## P39-2c 会话中心 + 报告 + 差异部分导航
- 会话中心 GUI（保存/加载/删除会话列表管理）
- 报告生成 `⌘P`（文本/HTML，接 htmlreport）
- 差异部分导航 `⇧⌃↓/↑`（区块级跳转）

## P39-2d 细节模式 + 布局 + 主页 + 书签
- 细节三模式（文本/16进制/对齐方式）
- 上-下布局 / 网页布局
- 主页卡片精修（圆角/阴影/hover/矢量图标）
- 书签 0-9 快捷键 `⌘⌥⌃0-9`（DiffTab）

## P39-2e 剩余项

- 忽略不重要差异
