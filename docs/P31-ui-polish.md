# P31 UI 精修（对标 Beyond Compare 视觉）

## 背景

功能已对标 BC 主能力（P28-P30 完成），但 GUI 视觉停留在"能用"：
egui 默认样式 + 少量半透明差异色，无底部状态栏、无工具栏路径输入框、
标签栏/按钮/间距均为默认观感。用户明确要求：**仔细打磨 UI 效果，参照 Beyond Compare**。

## 现状盘点（已摸底）

| 区域 | 现状 | 与 BC 差距 |
|---|---|---|
| 颜色系统 | common.rs 半透明差异底色（红/绿/黄），深浅主题通用 | BC 有明确"仅左=红/仅右=绿/修改=黄"配色 + 选中/当前行高亮层次 |
| 主窗口 | 顶部菜单栏（文本按钮）+ 标签栏 + CentralPanel | BC：工具栏含**路径输入框** + 图标按钮 + **底部状态栏**（统计） |
| 工具栏 | horizontal_wrapped + separator，纯文本按钮 | BC：图标 + 文本、紧凑分组、hover 提示 |
| DiffTab | 行渲染有 gutter + 差异底色 + 语法高亮 | 缺：当前行高亮、差异连接线感、选中态、行号栏底色 |
| DirTab | 树形文本渲染，[L]/[R]/[M] 状态字母 | BC：树图标、状态列着色、行选中/悬停、大小/时间列对齐 |
| CsvTab | 表头按钮 + 行渲染 | BC：表头固定、斑马纹、单元格对齐、选中行 |
| 主题 | system/dark/light 三档（egui 默认） | BC 深/浅色观感更精致（控件、边框、选中态） |
| 间距/圆角 | egui 默认 | 需统一视觉常量（行高、圆角、控件间距） |

## 目标

对标 BC 5 的视觉语言：**信息密度高、差异一目了然、工具栏精炼、状态可追踪**。

## 设计

### 1. 全局样式引擎（批次 1）

新建 `src/gui/theme.rs`，集中管理视觉常量与样式定制：

```rust
pub(crate) struct Theme {
    // 行高/字号
    pub row_h: f32,          // 22.0（比 20 略高，BC 行高舒适）
    pub font_mono: f32,      // 14.0
    // 间距
    pub panel_pad: f32,      // 工具栏/面板内边距
    pub item_gap: f32,       // 工具栏控件间距
    // 圆角
    pub corner: f32,         // 4.0（按钮/输入框/选中态）
}
```

- `apply(ctx)`：对 Dark/Light 两主题统一设置：
  - `spacing.item_spacing`、`button_padding`、`indent`
  - `visuals.widgets.*.corner_radius`、`selection.bg_fill`
  - `visuals.panel_fill`（深色下用更深的背景层次：顶层菜单/工具栏/内容区分）
  - 差异色按主题微调（深色下提高亮度）
- 视觉常量全部收敛到 theme.rs，各 tab 引用，去掉散落的硬编码

### 2. 差异配色对齐 BC（批次 1）

BC 语义：**仅左/删除 = 红，仅右/插入 = 绿，修改 = 黄**。
现有半透明色保留但统一命名与强度，新增：

| 角色 | 用途 |
|---|---|
| `bg_left_only` / `bg_right_only` | 行级"仅左/仅右"底色 |
| `bg_modified_l/r` | 修改行左右底色 |
| `bg_current` | 当前差异行高亮（比 match_current 更强的描边感） |
| `hl_current_l/r` | 当前行内变更段 |

- DiffTab 当前行：底色 + 左侧 3px 竖条（BC 风格当前行标记）
- 选中行与当前差异行分层（hover 浅、选中中、当前深）

### 3. 主窗口布局（批次 2）

- **底部状态栏**（`Panel::bottom`）：全局统计（当前 tab 差异数/总行数、目录对比统计、同步状态），
  与各 tab 内部统计栏去重（保留 tab 内，状态栏显示全局汇总）
- **工具栏路径输入**：DirTab 顶部加"左路径 | 右路径"只读文本框（点击可打开文件选择），
  对齐 BC 的路径栏观感；DiffTab 标题栏显示两侧文件名 + 差异统计徽标
- **标签栏美化**：当前标签高亮底色 + 圆角 + 关闭按钮 hover 变色（不再默认灰）

### 4. 各 tab 视觉精修（批次 3-4）

- **DiffTab**：
  - 行号栏底色与内容区分（gutter 背景微灰）
  - 当前差异行：背景 + 左侧竖条 + 行内变更段高亮
  - 差异连接视觉：删除/插入行错位时左侧对齐线（可选，先做底色层次）
- **DirTab**：
  - 目录行：▶/▼ 图标 + 文件夹色（深色主题下浅蓝）
  - 文件行：状态字母徽标（圆形/方形底）替代纯文本 `[L]`
  - 行 hover/选中底色 + 状态列固定宽度对齐
  - 文件大小列右对齐（等宽数字）
- **CsvTab**：
  - 表头固定 + 表头底色（与内容区分）、排序箭头对齐
  - 行 hover 底色、修改行双色沿用
- **MergeTab**：冲突行标记更醒目（红/黄底色 + 左侧竖条），已解决行显示 ✓ 绿标

### 5. 工具栏图标化（批次 4）

egui 无内置图标集，用 **Unicode 符号**（现有 ☁/⇄/⇱ 风格延续）统一：
刷新 ⟳、打开 📂、保存 💾、搜索 🔍、下一个差异 ⬇、上一个 ⬆、
取左侧 ←、取右侧 →、同步 ⇄。所有按钮统一 `icon + 文本` 或纯图标 + hover 提示。

## 批次计划

| 批次 | 内容 | 验证 |
|---|---|---|
| 1 | theme.rs 样式引擎 + 差异配色统一 + 全局应用 | 现有 382 测试全过；无头渲染不回归 |
| 2 | 主窗口：底部状态栏、标签栏美化、工具栏路径栏 | 状态栏统计正确；标签点击/关闭无回归 |
| 3 | DiffTab + DirTab 视觉（当前行竖条/状态徽标/行对齐） | 无头渲染 + 交互测试全过 |
| 4 | CsvTab/MergeTab/工具栏图标 + 收尾（README/CHANGELOG） | 全量门禁 + CI 三平台 |

每批完成即质量门禁（cargo test + clippy -D warnings + fmt）并提交推送。

## 风险与取舍

- egui 默认样式限制：不做像素级还原，追求"观感对齐 + 信息层次清晰"
- 差异色为半透明叠加，深浅主题都要可读（批次 1 按主题微调）
- 图标用 Unicode 符号（零依赖），不引入 icon 字体
- 无头测试不受视觉影响（uikit_tests 断言控件/状态，非像素）
