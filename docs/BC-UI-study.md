## 二、实测验证的交互

1. **视图过滤「显示差异」**（视图→显示差异 / 快捷键 2）：文件列表从全部（sub/a.txt/b.txt/leftonly.txt）→ 只显示差异文件（b.txt、leftonly.txt）✅
2. **「交换两边」**（会话→交换两边）：左右路径互换 ✅
3. **「复制到边...」**（操作→复制到边...）：点击执行 ✅

## 五、bcr DirTab 差距清单（BC 有 bcr 缺）

| # | 功能 | 说明 |
|---|------|------|
| D1 | 交换两边 | 会话菜单操作，DirTab 无 |
| D2 | 清除会话 | 回到空会话，DirTab 无 |
| D3 | 逐文件操作集 | 复制到边/移到一边/删除/重命名/属性/排除（右键+菜单），bcr 只有部分批量操作 |
| D4 | 视图过滤扩展 | 显示独有/较新项/不独有（bcr 有 All/Diff/LeftOnly/RightOnly/Same，缺"较新"维度） |
| D5 | 选择操作 | 选择较新项/独有项/反向选择 |
| D6 | 快捷键 1/2/3 | 视图过滤快捷键 |
| D7 | 展开/折叠全部 | 编辑菜单 |
| D8 | 报告/信息 | 文件夹比较报告、统计信息 |

## 七、文本比较视图实测（P36 追加，双击文件夹比较中的文件打开）

### 会话菜单（文本比较版）
新建/打开/保存会话、清除会话、**交换两边**、**重载文件(R)**、**重新比较文件(R)**、文本比较报告...(P)/信息、**比较文件使用**、**合并文件**、**比较父文件夹**

### 编辑菜单（核心编辑模型）
撤销(Z)/重做 | **对齐方式...(A)**（手动对齐）/**隔离**/替换内容... | **复制到右边**/**复制行到右边**/增加缩进(])/减少缩进([) | 剪切/复制/粘贴/删除 | 全选(A)/**选择选择内容(D)**/**把选择内容和剪贴板比较** | **转换文件**（Trim Trailing Whitespace/Tabs to Spaces/Line Endings）

### 搜索菜单（差异导航体系）
下一个/上一个差异 | **下一个/上一个差异部分**（Section 级）| 下一个/上一个差异文件 | **复制文件到右边并打开下一个差异** | 下一个/上一个替换 | **下一个/上一个编辑** | 查找...(F)/替换/查找下一个(G)/查找上一个

### 视图菜单
显示全部(1)/差异(2)/相同(3) + 过滤选项 + 图例(L)/日志/工具栏

### 实测交互：复制到右边
1. 执行后右侧文件被修改 → 窗口标题加 **`*` 星号**（未保存标记）
2. 弹出 **sheet 对话框**（保存/处理提示，AXSheet 模态）
3. ESC 关闭后修改保留，星号不消失
