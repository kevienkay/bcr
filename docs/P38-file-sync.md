# P38-1e 文件级联动（对标 BC Copy File and Open Next Difference）

> 背景：P38 深化批次最后一项，BC 差距补充表 T8（文件级联动）。
> BC 编辑菜单 → 复制文件到右边并打开下一个差异：整文件覆盖目标侧 + 跳到下一个差异。

## BC 命令语义

| BC 菜单项 | 语义 |
|---|---|
| 编辑 → 复制文件到右边并打开下一个差异 | 左侧整文件覆盖右侧 + 跳转下一个差异 |
| 编辑 → 复制文件到左边并打开下一个差异 | 右侧整文件覆盖左侧 + 跳转下一个差异 |

## 实施内容

### difftab.rs
- 新增 `copy_file_to(&mut self, target: EditSide) -> bool`：
  - 源侧整文件内容 → 覆盖目标侧文件（写回路径复用 copy_block_at：.bak 备份 + 编码回写 + 撤销快照 + 重载）
  - 重载后 `next_diff()` 跳到第一个差异（若无差异则清空 diff_pos）
- 右键菜单顶部加「⇨ 复制文件到右侧并打开下一个差异」/「⇦ 复制文件到左侧并打开下一个差异」
  （只有两侧都加载时显示，区别于块级复制）
- 已编辑标记：文件级复制把目标侧所有行标记为已编辑（整文件变更）

### 测试
- 单元测试：copy_file_to 覆盖目标侧全文 + 跳转；单侧加载返回 false
- uikit 测试：右键菜单项存在、点击后目标文件内容 = 源文件内容
