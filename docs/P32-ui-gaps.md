# P32 UI 差距消除：A 类核心交互 + B 类次要差距

对照 Beyond Compare 4 的 UI 特性差距清单（2026-08-12 盘点），全部实施。

## A 类：核心交互差距（7 项）

| # | 差距项 | 方案 |
|---|---|---|
| A1 | 差异连接线 | DiffTab 左右面板差异行之间画对齐连接线（egui painter 画线，颜色随差异类型：红/绿/黄），行高 ROW_H 内垂直居中 |
| A2 | 直接内联编辑 | DiffTab 行内双击就地编辑（TextEdit 替换行渲染），保存/ESC 退出；替代弹窗编辑；保留原弹窗入口兼容 |
| A3 | 同步滚动 | DiffTab 左右面板共用 ScrollArea 偏移（单 ScrollArea 双栏渲染 或 双向同步 scroll_offset）；实现为左滚动时右跟随 |
| A4 | 右键菜单全覆盖 | DiffTab/CsvTab/ImageTab/MergeTab 均加 context_menu（复制路径/打开所在位置/系统打开/复制到另一侧/交换），DirTab 已有则扩展 |
| A5 | 差异块折叠/展开 | DiffTab 差异块（连续差异行）行首加折叠箭头 ▸/▾，点击折叠该块（隐藏中间行，显示 "N 行已折叠"） |
| A6 | 撤销/重做 | DiffTab 编辑/替换操作入 undo 栈（Vec<EditAction>），Ctrl+Z 撤销 / Ctrl+Y 或 Ctrl+Shift+Z 重做；工具栏加 ↩/↪ 按钮 |
| A7 | 会话类型起始页 | 欢迎页扩展为完整会话类型选择：文本对比/文件夹对比/三路合并/图片对比/CSV 表格 + 打开文件/目录；网格卡片布局 |

## B 类：次要差距（7 项）

| # | 差距项 | 方案 |
|---|---|---|
| B1 | 快捷键系统化 | 全局：F6 下一差异/F7 上一差异（DiffTab）、Ctrl+Z/Y 撤销重做、F2 重命名（DirTab）、Ctrl+W 关闭标签；按钮 tooltip 带快捷键提示 |
| B2 | 过滤/显示面板 | DirTab 左侧 SidePanel：扩展名过滤、大小范围、时间范围（与工具栏过滤联动）；可折叠 |
| B3 | 状态栏信息 | 底部状态栏补：当前标签路径、行数/列数（DiffTab/CsvTab）、选中项数（DirTab） |
| B4 | 独立 Hex 对比视图 | 新建 HexTab（src/gui/nextab.rs）：左右十六进制并排 + 字节差异高亮 + 差异导航；CLI hex 路由 + 拖放 .bin/.exe 自动识别 |
| B5 | 标记忽略差异 | DiffTab 差异行右键「忽略此行/此块」→ 该差异从导航/统计中排除（会话级，可取消） |
| B6 | 标签拖拽排序 | 标签栏支持拖拽重排（egui drag 检测，拖拽中换位动画） |
| B7 | 工具栏图标细节 | 按钮统一紧凑间距 + tooltip 快捷键提示（如 "⟳ 重新加载 (F5)"）；检查所有按钮文字对比度 |

## 质量要求（用户明确）
- UI 美观整洁：无遮挡、无显示不全、无乱码、文字按钮清晰可读
- 每个批次补充 egui_kittest UI 自动化测试用例（新交互必须有测试）
- 全部 382+ 现有测试保持通过；clippy 0 警告；fmt 干净
- 每批次提交一次并推送，CI 三平台验证

## 批次划分
1. **批次 1（A1+A3）**：差异连接线 + 同步滚动（文本对比核心视觉）
2. **批次 2（A2+A6）**：内联编辑 + 撤销/重做（编辑闭环）
3. **批次 3（A5+B5）**：差异块折叠 + 标记忽略差异
4. **批次 4（A4）**：右键菜单全覆盖
5. **批次 5（A7）**：会话类型起始页
6. **批次 6（B1+B7）**：快捷键系统化 + 工具栏细节
7. **批次 7（B2）**：DirTab 过滤/显示面板
8. **批次 8（B3+B6）**：状态栏信息 + 标签拖拽排序
9. **批次 9（B4）**：独立 Hex 对比视图
10. **批次 10**：全量回归 + README/CHANGELOG 收尾
