## 二、菜单树总览（AX 实测）

### 2.1 全局菜单（所有视图共享框架）

- **Apple 菜单**：关于、设置 `⌘,`、文件格式、配置文件、检查更新、输入密钥、安装命令行工具、Hide `⌘H`、Quit `⌘Q`
- **会话（Session）**：新建会话（9 种：文件夹比较/合并/同步、文本比较/合并、16 进制、媒体、图片、表格）、新建标签页 `⌘T`、新建窗口 `⌘N`、打开会话 `⌥⌘O`、加载/保存工作空间、关闭窗口 `⌘W`、关闭所有窗口 `⌘⇧W`、保存会话 `⌥⌘S`、清除会话 `⌥⌘C`、交换两边、重载 `⌘R`、重新比较 `⌘R`、报告 `⌘P`、比较文件使用（视图切换）、合并文件、比较父文件夹
- **文件（File）**：打开文件 `⌘O`、打开剪贴板 `⌘V`、打开方式、保存 `⌘S`、保存为 `⌘⇧S`
- **窗口（Window）**：最小化 `⌘M`、缩放、选择标签页 `⌘]`/`⌘[`、合并所有窗口
- **帮助**：BC 帮助、网上 Scooter Software、支持

## 四、UI 样式观察（P39 精修参考）

### 4.1 整体布局（从实机截图观察）

- **主页**：顶部大 logo 区 + 左侧「会话」面板（保存的会话列表）+ 右侧 2×4 会话类型卡片网格（图标 + 标题 + 描述），底部「打开文件/目录/合并」按钮行
- **比较视图**：顶部工具栏（视图相关操作按钮）+ 左右（或左中右）并排内容区 + 底部状态栏；工具栏按钮多为图标+文字混合
- **文件头部**：文件名大字 + 下方小字详情（时间 | 大小），BC 5 的 detail 行在文件名下方
- **行号 gutter**：浅灰底 + 行号，宽度约 60px
- **差异高亮**：左侧删除 = 淡红底、右侧插入 = 淡绿底、修改 = 左右淡黄底 + 行内差异深色段；当前差异行左侧 3px 彩色竖条
- **状态栏**：底部信息条，含路径/统计

### 4.2 配色（深色模式观察）

- 背景：深灰（约 #1e1e1e）
- 差异色：删除 #7a3a3a 系、插入 #3a6a3a 系、修改 #7a6a2a 系（BC 经典柔和色调，非高饱和）
- 当前行竖条：蓝色系
- 选中/焦点：系统蓝

### 4.3 按钮与图标（P39 需要重点参考的细节）

- 工具栏按钮：小图标（16-20px）+ 可选文字，hover 有圆角底色反馈
- 常见图标语义（从截图辨认）：打开文件（文件夹）、保存（软盘）、刷新（环形箭头）、复制到右边（右箭头）、上一/下一差异（上下三角）、放大/缩小（放大镜）、旋转（弧形箭头）、翻转（水平/垂直镜像）
- **注意**：BC 的复制方向图标是「箭头指向目标侧」，与 bcr 现在用文字按钮「→ 复制到右边」一致
- 会话卡片图标：📄 文本、📁 文件夹、🔀 合并、🖼 图片、📊 表格、🔢 16进制、🔄 同步、🗂 文件夹合并（bcr 主页已用 emoji 近似，可换矢量图标）

### 4.4 细节模式（BC 特有，bcr 未实现）

- 视图菜单「细节」：文本细节 / 16 进制细节 / 对齐方式细节（同一视图切换三种渲染）
- 布局：边并排 / 上-下 / 网页（单栏）
- 缩略图（Overview）：右侧迷你差异地图（bcr 已有 A11 类似功能）
- 标尺：显示字符列标尺

## 五、bcr 对标差距清单（P39 精修候选）

### A. 功能缺口（建议分批实现）

| 优先级 | 功能 | BC 位置 | 备注 |
|---|---|---|---|
| P0 | 设置对话框 `⌘,`（语言/主题/忽略选项集中管理） | BC 菜单 | bcr 设置散落工具栏 |
| P0 | 会话保存/加载 GUI + 快捷键 `⌥⌘S` | 会话菜单 | 有 session 命令无 GUI 面板 |
| P1 | 报告生成 `⌘P`（文本/HTML） | 会话菜单 | CLI 有 htmlreport，接 GUI |
| P1 | 差异部分导航（区块级跳转） | 搜索菜单 | 有块模型未暴露导航 |
| P1 | 新建标签页 `⌘T` / 新建窗口 `⌘N` | 会话菜单 | 单窗口多标签已有，缺新建 |
| P1 | 打开剪贴板比较 `⌘V` | 文件菜单 | 有 load_clipboard 无菜单项 |
| P2 | 视图「细节」三模式切换 | 视图菜单 | 文本/hex/对齐 |
| P2 | 上-下布局 / 网页布局 | 视图菜单 | 目前仅并排 |
| P2 | 文本编辑「打开剪贴板」 | 文件菜单 | |
| P3 | 媒体比较（音视频） | 新建会话 | bcr 无 |

### B. UI 精修清单（样式层，可快速见效）

1. **配色对齐 BC**：重做 diff 色板（删除/插入/修改的柔和色调），当前行竖条改蓝色系
2. **工具栏图标化**：引入矢量图标（egui_extras SVG 或 icon font），替换部分文字按钮
3. **主页卡片精修**：卡片圆角/阴影/hover 动效，图标替换 emoji
4. **行号 gutter 样式**：浅灰底 + 等宽行号，与 BC 一致
5. **文件头部**：文件名 + 详情两行式（BC 5 风格），目前 bcr 已是两行
6. **状态栏**：统计信息排版对齐 BC
7. **字体**：中文思源黑体/苹方 + 等宽 JetBrains Mono，观感提升最大
8. **快捷键补齐**：`⌘,`/`⌥⌘S`/`⌘T`/`⌘G`/`⌘L`/`1-3` 等系统化注册

## 七、结论

BC 5.2.5 的完整 UI 结构已通过 **12 张实机截图 + 11 张官方截图 + 11 份菜单树（2668 行）** 记录在案。
P39 精修建议按「**功能缺口（A 表）** + **样式精修（B 表）**」两条线推进：
- A 表选 2-3 项先做（设置对话框、会话 GUI、报告）——功能对齐
- B 表 1-2 项并行（配色 + 字体）——观感立升
