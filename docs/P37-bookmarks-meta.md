## 实施内容

### PatchTab（patchtab.rs）
- 新增 `bookmarks: HashMap<u8, usize>`（编号 0-9 → 行索引）
- 工具栏/右键加「🔖 切换书签」「→ 书签」「清除书签」：
  - 切换书签：当前选中行（滚动位置）绑定编号（0-9，先做 0-9 循环或输入框）
  - 转到书签：跳转到对应行
  - 清除书签：清空
- 简化实现：工具栏加「🔖 切换书签(0-9)」按钮 + 输入编号；「→ 书签」跳转；「清除」
- 渲染：书签行显示 🔖 标记

### ImageTab（imagetab.rs）
- 工具栏加「ℹ 元数据」开关：显示左右图尺寸/格式（从 pair.stats + 文件扩展名）
- 混合切换已存在（show_overlay），不重复
