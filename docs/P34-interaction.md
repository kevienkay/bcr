# P34 交互模型对齐 BC — 空会话优先 + 拖拽导入

> 用户反馈：① 首页文本对比/文件夹对比卡片点击"无法跳转"；② 文本对比必须选两个文件才能进页面；③ 不支持拖拽导入。
> 根因：bcr 沿用「先弹文件对话框 → 选满 N 个文件 → 才进入会话」的旧模型，与 BC 的「先进入空会话 → 再分别打开/拖拽左右两侧」相反。

## BC 5.2.5 交互模型（实测）

- 点「文本对比」→ **立即进入空会话**（左右两个空面板，各显示"打开文件"入口）
- 点「文件夹对比」→ 空目录对比（左右各显示"选择目录"入口）
- 文件/目录可**拖拽**到窗口或某个面板上直接填充
- 打开文件用「打开左侧/打开右侧」分别操作，不强求一次选满

## 现状差距

| # | 差距 | 现状 | 目标 |
|---|------|------|------|
| A1 | 首页卡片点击 | 弹两次文件对话框，取消即无响应（"无法跳转"） | 直接进入空会话 |
| A2 | 文本对比入口 | `open_diff_files` 强制 `pick_file()` ×2 | 空 DiffTab，面板内分别打开 |
| A3 | 拖拽 | 有 `handle_dropped` 窗口级拖拽，但空会话无拖拽提示 | 空面板显示拖拽提示 + 拖到侧面板填充 |
| A4 | 目录对比入口 | 强制选两个目录 | 空 DirTab，面板内分别选择 |
| A5 | 合并/图片/CSV 入口 | 强制选满 N 个 | 空会话 |

## 实施（3 批）

### 批次 1：空会话入口 + 空路径守卫
- mod.rs 新增 `open_empty_diff/dir/merge/image/csv`，首页卡片 & 菜单栏 Session 菜单改调空会话
- DirTab/MergeTab/CsvTab 空路径守卫（空时不自动 refresh/reload，避免报错）
- 各 Tab 空状态显示友好提示

### 批次 2：空面板 UI（打开入口 + 拖拽提示）
- DiffTab 空状态：左右两个"打开左侧/打开右侧"大按钮 + 拖拽提示
- DirTab 空状态：左右"选择目录"按钮 + 拖拽提示
- MergeTab/ImageTab/CsvTab 空状态入口

### 批次 3：拖拽到侧面板填充
- 拖单个文件到空 DiffTab 左/右侧面板 → 填充对应侧
- 拖目录到空 DirTab → 选择对应侧
- 空会话中拖拽提示高亮
