# P38-1c 文本对比缩进调整（对标 BC Increase/Decrease Indent）

> 背景：P38 深化批次第三项，BC 差距补充表 T4（增加/减少缩进）。
> BC 编辑菜单 → 缩进：对选中行/差异块整体增加或减少缩进（默认 4 空格）。

## BC 命令语义

| BC 菜单项 | 语义 |
|---|---|
| 编辑 → 缩进 → 增加 (Increase Indent) | 选中行左侧 +4 空格 |
| 编辑 → 缩进 → 减少 (Decrease Indent) | 选中行左侧 -4 空格（不足则去头部空白） |

## 实施内容

### difftab.rs
- 新增 `indent_block(&mut self, row: usize, delta: isize) -> bool`：
  - 定位 row 所在差异块（与 copy_block_at 同定位）
  - 对块内两侧**存在**的行：左侧内容 ± delta 空格（仅行首空白变化，非空白行）
  - 写回目标两侧（复用 copy_block_at 的写回路径：.bak 备份 + 编码回写 + 撤销快照 + 重载）
- 右键菜单差异块：追加「↦ 增加缩进」「↤ 减少缩进」（4 空格/次）
- 缩进只改行首空白：`pad = " ".repeat(4)`，减少时去掉最多 4 个前导空格

### 测试
- 单元测试：块内行两侧缩进 +4/-4；空白行不变；无选中返回 false
- uikit 测试：右键菜单项存在、点击后文件内容缩进变化
