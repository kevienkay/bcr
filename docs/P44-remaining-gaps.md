## 批次计划（每批：cargo test 全绿 → fmt → clippy 0 → 单提交推送）

- **P44-1 窗口菜单 + 标签切换**：窗口菜单（选择下一/上一标签页 ⌘]/⌘[、最小化 ⌘M、关闭所有窗口 ⌘⇧W）+ DiffTab/DirTab 等标签切换快捷键
- **P44-2 文本比较快捷键**：⌘A 对齐方式、]/[ 缩进、⌘E 使用选择内容查找（选区→查找框）
- **P44-3 文本合并快捷键**：采用左边/中心/右边（⇧←/⇧→）、左后右 ⌘B / 右后左 ⇧⌘B、行级采用（⌥⇧←/→）、清除冲突区段下一、冲突部分导航快捷键（⌘⇧⌃↓/↑）
- **P44-4 会话/文件菜单补齐**：打开会话 ⌥⌘O、保存会话为、已锁定（DiffTab 防编辑开关）、打开方式（关联应用/在 Finder 显示）、保存文件为 ⌘⇧S、⌘R 重新比较
- **P44-5 工具菜单补齐**：导出/导入设置（settings.toml）、恢复出厂默认、编辑文本文件/查看补丁入口（对应 TextEdit/PatchTab 已有视图）
- **P44-6 视图开关 + 表格快捷键**：DiffTab 行号/语法加亮菜单开关；CsvTab 修改 ⇧⌃↩、前后插入行快捷键、排序对话框
- **P44-7 搜索补齐**：DirTab 查找文件名（⌘F）、TextEdit 在多个文件中查找、⌘E 使用选择内容查找（跨视图）
